# SparkHacks Archive
Archive of past SparkHacks websites, preserved for reference as the current site evolves year to year. Currently under construction.

## Getting Started

```bash
git clone git@github.com:SparkHacks/sparkives.git
cd archive
npm install
```

## Running Locally

```bash
npm run dev
```
